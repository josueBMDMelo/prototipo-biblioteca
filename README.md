# Protótipo Web e Testes Manuais

Parte 1 — Criação das páginas
- Criar três páginas: login, listagem e cadastro, de acordo com o tema do projeto.
- Estilizar as páginas com CSS em arquivo separado.
- Implementar em JavaScript a validação dos formulários, exibindo mensagens de erro e de sucesso.
- Armazenar os dados no próprio navegador (array em JavaScript ou localStorage); não é necessário back-end nem banco de dados.
- Os itens cadastrados devem aparecer na página de listagem.
  
Parte 2 — Testes manuais
- Elaborar no mínimo 8 casos de teste, incluindo cenários válidos e inválidos.
- Executar os casos no protótipo e registrar o resultado obtido e o status (Passou / Falhou).
- Preferencialmente, quem executa o caso não deve ser quem o escreveu.
- Registrar como defeito todo caso que falhar, com print salvo na pasta testes/.
- Após corrigir o defeito, executar o caso novamente (reteste).
